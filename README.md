# xiaoyuzhou-podcast-search

检索小宇宙近期播客节目的网页小工具：把选定播客的最新节目列出来供搜索，点击任意一期，跳转到小宇宙的播放页收听。

## 当前进度

- [x] 仓库建立
- [x] 第一版页面：搜索框 + 节目列表 + 点击跳转
- [x] 填入真实数据：全站热门单集 Top 50（数据源见下）
- [x] 每周自动更新数据（由 Muse 每周一、周四约 10:00 运行抓取脚本并提交）
- [ ] 按播客聚合的热度榜（把同一播客的多期合并排名）

## 数据来源

小宇宙官方没有公开的全站热度榜接口。当前数据来自「播客良品铺子」每周发布的
《播客周榜》——按播放量排列的全站热门单集榜（非官方整理），由抓取脚本
从榜单单集的 shownotes（节目介绍）中提取名次、播客名、标题和播放链接。

## 文件

- `index.html`：页面本体（搜索框 + 节目列表 + 点击跳转）
- `data.js`：节目数据，由抓取脚本自动生成，**请勿手改**
- `scrape_chart.py`：抓取脚本，自动找最新一期周榜并生成 `data.js`

## 用法

用浏览器打开 `index.html`，在搜索框输入关键词即可筛选节目；点击任意一期，打开它的小宇宙播放页。

更新数据：平时不用管，Muse 每周一、周四会自动运行抓取脚本，有新一期周榜时
把 `data.js` 更新到仓库。想立刻更新，本地运行 `python3 scrape_chart.py`
再提交 `data.js` 即可。
