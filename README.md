# xiaoyuzhou-podcast-search

检索小宇宙近期播客节目的网页小工具：把选定播客的最新节目列出来供搜索，点击任意一期，跳转到小宇宙的播放页收听。

## 当前进度

- [x] 仓库建立
- [x] 第一版页面：搜索框 + 节目列表 + 点击跳转（节目数据暂时是示例）
- [ ] 选定第一批播客，填入真实节目数据
- [ ] 想办法自动拉取最新节目

## 文件

- `index.html`：页面本体。节目数据写在文件里的 EPISODES（节目列表）数组中，每期包含：播客名、单集标题、发布日期、小宇宙播放页链接。

## 用法

用浏览器打开 `index.html`，在搜索框输入关键词即可筛选节目；点击任意一期，打开它的小宇宙播放页。
